一、基本信息
项目	内容
游戏名	《试镜人生》（暂定，备选《烂片女王》《表情试镜》）
一句话描述	你是无名演员，自由组合表情拼出试镜片段，投给各家影视公司，在21天（游戏内周数）内凑齐PS5费，走向不同人生结局。
类型	模拟 / 叙事 / 轻策略
平台	PC+手机
引擎	Godot
开发周期	21天，3人
参考	《Papers, Please》的审核循环 + 《密教模拟器》的碎片化叙事 + 《颈椎病》的美术风格

二、核心循环



核心目标： 在固定周数内凑齐一笔PS5费。
失败条件： 没有凑够PS5费。

三、玩法机制
3.1 表情组合
●表情拆分为部件： 
○五官部件：眼睛、嘴巴、眉毛
○其他部件：黑线：(￣_￣|||)，青筋：生气(╬▔皿▔)╯，等
○部件属性：如：喜/怒/哀/惊/魅/尬…
●玩家自由组合，不是凑标准答案，而是“我想演成什么样”
●选择机制：页签 + 点击
●组合好会显示标签
3.2 公司与判定
随着游戏进程，玩家可以投递不同的公司。
公司	演技门槛	偏好	成功收益	适合阶段
A 烂片厂	0	随便	演技+1，钱少	前期
B 小公司	3	喜/悲	演技+1，钱少	前期
C 商业片	8	纯真	演技+2，钱中	中期
D 文艺片	15	幻灭	演技+3，钱中	中期
E 大厂	25	反转	演技+5，钱多	后期
其中CDE靠后期解锁。
角色难度
同一家公司，可能有不同难度的角色：
角色	演技要求	匹配度要求	收益
龙套	0	30%	+1
配角	5	50%	+2
主角	15	70%	+5
演技值
获取演技值，用于提升角色能力，以及获得投递其他公司的机会。
来源	演技值
成功试镜（小角色）	+1
成功试镜（配角）	+2
成功试镜（主角）	+5
被拒绝	+0（但可能+1经验？）
特殊事件	不定
3.3 叙事系统
●碎片化叙事：邮件 + 新闻推送 + 事件节点
●同一事件按玩家属性生成剧情差分
●留白，让玩家自行脑补
3.4 资源与压力
玩家需要管理的是金钱，金钱包含支出、收入、随机事件三个部分：
●收入来源
来源	钱	演技值	备注
试镜成功	多	少	还会提升演技
打工	少	0	保底，但占时间
随机事件	不定	不定	机遇
●支出项目
支出	钱	效果	备注
房租	中	不交掉状态	每周固定
表演课	中	+演技	主动投资
~~经纪人礼物~~	—	—	🛑 **Day 0 已砍**：好感系统整体砍掉，此项失去存在意义
PS5费	大	目标	分期交
●随机事件
事件	选项A	选项B
导演邀你试镜	去（花钱+时间）	不去（省钱，但错过机会）
~~经纪人推荐烂片~~ → **熟人推荐烂片**	接（钱多，演技不涨）	拒	🛑 **Day 2 改名**：经纪人角色已砍
朋友借钱	借（-钱，+好感）	不借（省钱，-好感）	⚠️ Day 0：「好感」已砍，收益需要重设计
表演课打折	买（-钱，+演技）	不买（省钱）
总结：为了达到平衡以及好结局的目的，玩家需要在有限的金钱里面做出取舍。
●演技值是一种“投资”，前期花钱上课，后期才能赚更多。
●日常需要一定的支出来维持生计，以及阶段性的需要缴纳PS5费避免提前触发bad ending。
●随机事件风险与机遇并存，可能这一次的提升就能让主角够到大公司的门槛，进而获得一笔雪中送炭的资金。

3.5 一周流程

┌─────────────────────────────────────────┐
│  阶段1：周初（事件推送）                  │
│  - 收到邮件 / 新闻                        │
│  - 触发本周事件（随机或条件）              │
│  - 玩家阅读，可能做出选择                  │
├─────────────────────────────────────────┤
│  阶段2：周中（投递试镜）                  │
│  - 玩家可投递 2 次                        │
│  - 每次：选部件 → 组合 → 选公司 → 投递     │
│  - 立即看到结果                           │
├─────────────────────────────────────────┤
│  阶段3：周末（结算）                      │
│  - 扣房租                                 │
│  - PS5费分期扣款（如到期）                │
│  - 更新演技值 / 好感 / 状态                │
│  - 显示本周总结                           │
├─────────────────────────────────────────┤
│  阶段4：周结束（判定）                    │
│  - 检查结局条件                           │
│  - 未触发 → 进入下一周                    │
│  - 触发 → 进入结局                        │
└─────────────────────────────────────────┘

3.6 结局
结局	条件
影后	演技值 ≥ 30，凑齐PS5费
文艺片女神	演技值 ≥ 20，且演过D公司主角
烂片女王	演技值 ≤ 10，但演出次数 ≥ 15
龙套之王	演技值 ≤ 5，演出次数 ≥ 20
被解雇	多轮无戏 + 欠债
平庸	两者都不高，勉强凑齐

●手机
○微信：联系HR（**投递入口**），联系其他人（随机事件）	🛑 **Day 0/2**：投递从 Boss直聘 移到微信；~~联系经纪人~~ 已砍

五、美术
风格：
●色块 + 线条的剪纸拼贴风，参考《颈椎病》
●纯色块区分部位，少量噪点/指纹纹理
●抽象卡通化，降低绘制压力，提升代入感
●表情部件参考网络梗图/表情包
●UI 与整体风格一致

六、音效
●邮件收发提示音
●表情部件拖拽/组合音
●公司回复音（好/烂/拒绝差分）
●新闻推送音
●BGM：1~2首循环（压抑/荒诞）

七、范围边界
类别	内容
必须做	表情组合、投递判定、5~7个公司、邮件+新闻叙事、1个核心结局、PS5费目标
可以砍	多余结局、角色动画、复杂属性系统、多周目
绝对不做	多人、存档系统、成就、多语言、精细人物绘制
