## D. 数值可达性核对（文档里有两条做不到）

| 事实 | 出处 | 影响 |
|---|---|---|
| 一周最多投递 **4** 次，共 **3** 周 | `GameState.MAX_SUBMIT_PER_WEEK = 4`、`WEEKS = 3` | **累计最多 12 次投递**，其中成功只会更少 |
| 演技上限 **30** | `BalanceData.acting_cap = 30` | 文档「≥30」= 顶到天花板才算，几乎不可能；代码用 25 是算过的 |
| 龙套之王「演出次数 ≥ 20」 | 本文档结局四 | **不可能达成**（上限 12） |
| 烂片女王「演出次数 ≥ 15」 | 本文档结局三 | **不可能达成**（上限 12） |
| 影后「演技 ≥ 30」 | 本文档结局一 | 与 `acting_cap` 相撞，等于要求满值 |

结论：结局三、四的「次数」阈值必须往下调，或改成代码现在用的口径
（**龙套数数量、烂片数品质** —— 这个区分在 `ending_resolver.gd:106-108` 有明确理由）。
