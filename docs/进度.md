## 数值模拟器的三条结论

`Godot --headless --path <项目> --script res://tools/simulate.gd -- 300`

跑法：**随机 agent**（什么都不学，乱拼乱投）给出下界，**贪心 agent**（读懂线索 + 算得清账）
给出上界，中间三档模拟「懂了但手潮」。每档 300 局。

### 结论 1 —— 「影后」曾经不可达（✅ 已修复）

**发现**：E 大厂演技门槛写着 25，而玩家在**任何一个可投递时刻**能有的最高演技是 **21**：

```
第 1 周  表演课 +3，龙套 ×4（+1）→ 7      ← 一周内演技不变，只有表演课是即时的
第 2 周  表演课 +3，配角 ×4（+2）→ 18
第 3 周  表演课 +3 → 21，然后这一周就结束了
```

**原因**：演技的增量在**周末结算**时才兑现（决策 1.5），所以每一周**之内**演技是冻结的。
门槛 25 越过了这条线 → E 公司在任何时刻都投不进去 → 挂在上面的「影后」变成死结局。
数值表 3 那句「第 3 周练到 25 之后，当周还剩 1 次投递额度正好投 E 主角」，
默认了演技**当周生效** —— 与决策 1.5 冲突。

**修法**（Day 2 拍板 A）：**E 门槛 25 → 20**，只动生成脚本里一个数。
影后自身的条件「演技 ≥ 25」**不用改** —— 它在第 21 天结算之后才判，那时演技已到 30。

|---|---|---|

| 23 | 0.0% | 100.0% |
| 21 | 100.0% | 0.0% |

**四个坑（都踩过）**：

1. **命令行的导出写完之后进程不会自己退** —— `godot_mcp` 插件在编辑器模式下常驻。
   `[ DONE ] export` 那行出现时文件**已经落盘**，所以：后台跑 + 看到 DONE 就结束进程，
   别等它自己退（我第一次等了 12 分钟）
2. **`tools/` 与 `addons/` 必须排除**，否则 44 个开发脚本 + 69 个 MCP 插件文件会被打进包
   （80.5MB → 76.2MB）。已经写进 `export_presets.cfg` 的 `exclude_filter` ——
   **把那个会开 HTTP 监听的编辑器插件打进游戏**尤其不能忍
3. **`--install-android-build-template` 不能单独用**，必须和 `--export-*` 一起
   （`--help` 里写了 "Used in conjunction with"）。单独跑它只会打印一行版本号就退出
4. **导出包里目录扫描会扫空** —— 打包后 `.tres` 的真身被换成二进制 `.res` 藏进
   `res://.godot/exported/`，原路径上只留一个 `xxx.tres.remap`。于是
   `dir.get_files()` 返回的是 **`xxx.tres.remap`**，而 `if not f.ends_with(".tres")`
   这种写法**在编辑器里全对、一打包就 0 条命中**。真实后果（10-11 踩到）：
   **录像机 32 件部件读成 0**（界面一个可选表情都没有）、**微信 5 封模板读成 0**（收不到回信）。
   现在一律走 `ResourceDir.list_tres()` —— 剥掉 `.remap` 之后**用原始 `.tres` 路径** `load`，
   `ResourceLoader` 自己会顺着 remap 找到真身。**新加数据目录一律走它，别再手写 DirAccess 循环。**

**第一次构建会下 Gradle 与依赖**，本机 `~/.gradle` 现在 3.5GB。之后改了 GDScript
再导只需约 35 秒（Java 侧没动、缓存命中）。

**出包后必查（编辑器里跑不出来的那一类）**：headless 测试跑的全是编辑器形态，
所以下面这两件事**只能在真机/导出包上确认**，每次出包都点一遍：

- **录像机**：四个页签（眼睛 / 嘴 / 眉毛 / 其他）里都有可选项，不是空的
- **微信**：「发送表情包 = 投递」之后能收到回信，不是石沉大海

（坑 4 就是这么漏到玩家手上的。装到手机上 10 秒能看出来。）

**还没做的两件事**（都归 M5）：
- **release keystore** —— 现在只有 debug。上架要自己的 release keystore
  （**密码别进仓库**），导出格式也要从 APK 换成 AAB
- **Android 启动图标** —— 现在是空的（回退到 `icon.svg`）。Android 要 192×192
  与自适应图标的 432×432 前景/背景 —— 扉师交图后填进导出预设
