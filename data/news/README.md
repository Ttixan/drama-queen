# 电子报《有瓜有戏》— 规则

> 内容来源：`各公司试镜邮件与电子报反馈文案-初版整理.docx`（已去除来源链接）
> 用途：每周日结算时播出的电子报，玩家在**微博**中阅读

## 核心区分：作品质量 ≠ 玩家表现

> 一部烂剧里可以有演得出色的演员，一部好剧里也可以有表现失常的演员。

- **作品质量（公司档次）** 决定标题的**背景**
- **玩家表现（匹配度）** 决定标题**是否夸奖或批评玩家**
- 公司类型用于选择**文案口吻**；好剧或烂剧仍应按**本次项目的结果**判定

## 结果三档

| 档位 | 玩家收到的反馈 | 累积方向 |
|---|---|---|
| **高分** | 表演获得关注，可能带来出圈机会 | 获得正面影响力与知名度 |
| **普通** | 不温不火；龙套可能只看到剧集新闻 | 无明显个人舆论变化 |
| **低分** | 表演遭到批评；被关注时产生负面讨论 | 风评下降，并可累积黑红条件 |

## 标题如何称呼玩家

| 出演情况 | 标题称呼与呈现方式 |
|---|---|
| 无知名度的龙套 | 通常不写玩家名，用"龙套""演【角色名】的那位"，或直接写"保安""前台"等角色 |
| 无知名度的主要角色 | 用"男主""女二""反派"等角色定位；不直接假设观众已经认识演员 |
| 表演首次出圈 | 可出现"演【角色名】的是谁"等**找人标题**，表现观众从注意表演到寻找演员的过程 |
| 已有一定知名度 | 可以直接使用【玩家名】，包括这次仅出演龙套或客串的情况 |

> 龙套高分时，好剧可写"连龙套都演得好"，烂剧可写"主角还不如龙套"。
> 普通龙套未引起讨论时，标题只谈剧集；低分龙套也不必每次都成为新闻。

## 知名度 / 风评 / 负面曝光 如何累积

| 播出后情况 | 知名度 | 风评 | 负面曝光 |
|---|---|---|---|
| 高分且个人表演被关注 | 上升 | 上升 | 不增加 |
| 普通表现，未引起个人讨论 | 无明显变化 | 无明显变化 | 不增加 |
| 低分且个人表演被吐槽 | 可上升 | 下降 | 增加 |
| 龙套低分，但没有被注意 | 无明显变化 | 无明显变化 | 不增加 |
| 新闻只批评全剧或公司 | 不自动增加 | 不自动下降 | 不计入个人累计 |

> **正面影响力**属于高分带来的收益；**知名度**可以由赞扬或骂声带来。
> 负面新闻出现后，不应把"更多人认识玩家"直接等同于"玩家口碑变好"。

## 黑红也是红

- **触发方向**：玩家因多次负面表演反馈而被反复讨论，相关累计达到门槛
- **注意**：GDD 的「范围边界」写明"绝对不做成就系统"
  → **本设计不做成成就，改为一条微博标题**（见 `headlines.md` 的「黑红反馈」段）
- **门槛数值待定**，见 `docs/数值表_v1.xlsx` sheet「5-知名度风评黑红」

## 标题调用条件

部分标题需要玩家**过往经历**才能调用，否则改用通用备选：

- "只会演烂剧""不演霸总"等说法 → 需要对应的**过往经历**
- "演活了一个死人""改演木头" → 需要对应的**表情僵硬的失败**

> 这意味着需要一个**玩家履历标记系统**。目前方案：**录像机的表情包列表天然充当履历**
> （表情包一次性消耗，按时间顺序记录"你演过什么"），见 `docs/开发计划.md` 1.6 / M2。
