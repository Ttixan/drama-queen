# 试镜邮件模板 — 说明

> 内容来源：`各公司试镜邮件与电子报反馈文案-初版整理.docx`（已去除来源链接）
> 用途：微信私聊 HR 的投递结果回信

## 结构与语义

- **「试镜成功」= 角色已确定由玩家出演**，不代表剧集质量好
- 每封邮件包含 **主题 / 正文 / 署名**，可单独复制
- **邮件用【角色名】明确通知定角结果**；新闻（电子报）用【报道对象】控制是否点名
- 具体身份用于让玩家看出新闻说的是自己的角色

## 替换字段

| 字段 | 填写内容 |
|---|---|
| `【玩家名】` | 玩家角色的姓名或艺名 |
| `【公司名】` | 本次项目所属公司的名称；邮件署名中的 A—E 同步替换 |
| `【剧名】` | 玩家参演的作品名称 |
| `【角色名】` | 人物姓名或"保安""前台"等具体身份 |
| `【角色定位】` | 主角、男主、女二、反派、配角、龙套等戏份或定位 |
| `【日期】` | 本次进组日期 |
| `【地点】` | 拍摄地点 |
| `【截止时间】` | 回复期限 |
| `【报道对象】` | 根据知名度与戏份，选择玩家名或"男主""女二"等称呼 |
