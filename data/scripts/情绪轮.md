· 悲伤
· 厌恶

## 二、复合情绪（24种）
### 初级复合情绪（8种）
· 爱 = 喜悦 + 信任
· 顺从 = 信任 + 恐惧
· 敬畏 = 恐惧 + 惊讶
· 失望 = 惊讶 + 悲伤
· 悔恨 = 悲伤 + 厌恶
· 轻蔑 = 厌恶 + 愤怒
· 攻击性 = 愤怒 + 期待
· 乐观 = 期待 + 喜悦

### 次级复合情绪（8种）
· 内疚 = 喜悦 + 恐惧
· 焦虑 = 期待 + 恐惧
· 喜悦（Delight）= 喜悦 + 惊讶
· 绝望 = 恐惧 + 悲伤
· 羞耻 = 恐惧 + 厌恶
· 嫉妒 = 悲伤 + 愤怒
· 悲观 = 悲伤 + 期待
· 病态 = 厌恶 + 喜悦

### 三级复合情绪（8种）
· 自豪 = 愤怒 + 喜悦
· 支配 = 愤怒 + 信任
· 好奇 = 信任 + 惊讶
· 多愁善感 = 信任 + 悲伤
· 宿命论 = 信任 + 期待
· 休克 = 惊讶 + 厌恶
· 愠怒 = 悲伤 + 愤怒
· 愤怒（Outrage）= 惊讶 + 愤怒
