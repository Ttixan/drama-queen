## 格式说明

解析器只认两种小节标题：

- `## 第 N 周` —— 这一周的**专属事件**（那一周就该演那一出，优先级自动最高）
- `## 通用池` —— 不挑周次的池子，哪一周缺事件就从这里抽

其他小节（比如本段）会被忽略，写什么都不会进游戏。

每个事件用 `### 随便什么标题` 开头，下面跟一张 `| 字段 | 内容 |` 表。
字段只有下面这些，**写错一个字段名会当场报错退出** —— 不会悄悄丢掉这段文案：

| 字段 | 必填 | 说明 |
|---|---|---|
| `事件代号` | ✅ | 内部 id，只用字母数字下划线。**改它等于改存档**（「出现过没有」按它记），别随便改 |
| `说话人` | ✅ | 微信里显示的名字（「王导」「老同学」） |
| `说话人代号` | ✅ | 同一人共用，只用字母数字下划线 |
| `开场白` | ✅ | 他找上门时说的第一句 |
| `可重复` | | 填 `是` 表示同一局里能出现第二次 |
| `需钱` | | 手里至少这么多钱才出现（不填 = 不设门槛） |
| `需演技` | | 演技至少这么多才出现（不填 = 不设门槛） |
| `选项A` / `选项B` | ✅ | 按钮上的两个字 |
| `A回话` / `B回话` | ✅ | 玩家选完之后对方回的话 |
| `A行动点` / `B行动点` | | 消耗几点行动点（不填 = 0） |
| `A钱` / `B钱` | | 钱的变化，负数就是花掉 |
| `A演技` / `B演技` | | 演技的变化 |
| `A知名度` / `B知名度` | | 知名度的变化 |
| `A风评` / `B风评` | | 风评的变化 |
| `A结果` / `B结果` | | 履历与结算里显示的结果说明 |

**两条硬规则**（生成脚本会拦）：

1. **必须正好两个选项**，且按钮文字不能空
2. **至少一个选项不花行动点** —— 行动点是一天一点、不能欠的资源，
   要是两个选项都收行动点，把当天这点花光的玩家就会被卡死在这一周。
   GDD 本来就给了出路：每个事件的拒绝项（不去 / 拒 / 不买）都是免费的
