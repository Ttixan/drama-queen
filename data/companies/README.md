# 公司信息页 — 总览

> 内容来源：`五家公司Boss招聘页面文案初版.docx`（已去除真实招聘页链接与来源章节）
> 用途：游戏内 Boss直聘 App 的公司信息展示页

## 定位

| 代号 | 定位 |
|---|---|
| **A** | 流水线烂片小厂，短剧内容几乎都是大量重复的同类低智剧本 |
| **B** | 小公司特有的神人 HR 和学徒制招聘 |
| **C** | 完整五险一金待遇，正规公司招聘，字少 |
| **D** | 文艺逼开的公司，要求多＋需要的学历高，有愤青味道，字里行间抨击烂片厂 |
| **E** | 大厂但周扒皮，不止 996，有很多夸张要素（如休息两月一休、每日上班 18~23 小时等）。用夸张表现反讽资本家，同时通过"这种待遇结果却是游戏里玩家能接触最好的公司，还是规模在 9999 人以上的上市大厂"进行现实联想，制造黑色笑话 |

## 玩家行为说明

- 每家公司**只展示一个代表性职位**
- **玩家不在此页面求职** —— 本页仅作公司信息浏览与 HR 信息展示
- 投递动作在**微信私聊 HR** 中完成（见 `docs/开发计划.md` 1.5 核心循环）

## 制作备注

- 本文供游戏内公司信息页面使用
- 页面中的薪资、公司规模和夸张条款为**游戏虚构设定**，不代表任何真实招聘主体
- E 公司的极端工时为讽刺性夸张
- B 公司文案中**不含任何「五险一金」表述**（已按修改要求删除标签及正文相关表述）
