# 公司信息页 — 总览

> 内容来源：`五家公司Boss招聘页面文案初版.docx`（已去除真实招聘页链接与来源章节）
> 用途：游戏内 Boss直聘 App 的公司信息展示页

## 定位

| 代号 | 定位 |
|---|---|
| **A** | 流水线烂片小厂，短剧内容几乎都是大量重复的同类低智剧本 |
| **B** | 小公司特有的神人 HR 和学徒制招聘 |
| **C** | 完整五险一金待遇，正规公司招聘，字少 |

## 玩家行为说明

- 每家公司**只展示一个代表性职位**
- **玩家不在此页面求职** —— 本页仅作公司信息浏览与 HR 信息展示
- 投递动作在**微信私聊 HR** 中完成（见 `docs/开发计划.md` 1.5 核心循环）
- **拿到 HR 联系方式这一步，要跟 HR 说上话**：点招聘页上的 HR 卡 → 进聊天界面 →
  把下面的「初次沟通」逐句放完 → HR 说「加微信」→ 联系人进微信（从此可以私聊投递）

## 「## 初次沟通」怎么写

每家 md 末尾有这一节。它是**点 HR 之后那段有来有回**，格式是一张两列表格：

```
| 谁 | 话 |
|---|---|
| HR | 你好，编剧岗还在招。 |
| 选 | 我没写过短剧，但想试试。 |
| 选 | 我写过网文，不知道合不合适。 |
| 选 | 日更的节奏我能跟上。 |
| HR | 加我微信，我们微信上聊。 |
```

- **「谁」只能写四个词**：`HR` / `我` / `选` / `系统`（`系统` 是居中的小字提示，一般不用写）
- **顺序就是播放顺序**，一句一气泡，自动往下走
- **`选` = 给玩家挑的回复**：**连着写几行**就是一组选项，界面上竖排成几个按钮；
  玩家点了哪句，哪句就作为他自己发的消息出现
- **三个选项可以各有各的回复**：在「谁」后面加 `@n` 表示「只属于第 n 个选项的支线」——
  `HR@1` 是选了第 1 个才会说的话，`我@2` 同理。**公共的行不写 `@`**。
  支线按 `@1`、`@2`、`@3` 的顺序排在选项后面即可，播放时会跳过没选的那几条：

  ```
  | 选 | 问问薪水 |
  | 选 | 问问签约制度 |
  | 选 | 问问怎么试镜 |
  | 我@1 | 请问薪资怎么算？ |
  | HR@1 | 可以日结，一天100。 |
  | 我@2 | 是项目合作还是长期合同？ |
  | HR@2 | 有活就叫你，没活就歇着。 |
  | 我@3 | 试镜什么流程？ |
  | HR@3 | 加我微信，我发你剧本。 |
  ```

- **玩家挑过哪句会被记住**（进存档）：第二次点开这家**不再演一遍、直接铺完**，
  铺的是**他当初挑的那句**（以及那条支线），不是第一句。⚠️ 因为记的是**序号**，
  把一组选项**调换顺序**会让老存档里那句的意思跟着变 —— 要调就尽量把新的加在后面
- **最后一句建议留给 HR 收尾**（把玩家引到微信）—— 界面上「拿到联系方式」的提示
  由程序发，不用你写
- 表格上面的 `>` 引用行只是给你看的备注，**不会显示到游戏里**
- 制作备注（如「（数值提提改）」）**不要写进表格**，表里的每个字玩家都会看到

## 「## 微信开场」怎么写

加进微信后**第一次点开这位 HR** 时的聊天记录（docx 里叫「界面二：微信聊天记录」）。
表格格式与「## 初次沟通」**完全一样**（同样支持 `@n` 支线，一般用不上）：

```
| 谁 | 话 |
|---|---|
| HR | （发送文件：《试戏片段.pdf》） |
| HR | 先试这个通用剧本，你看了剧本今晚自己录个视频发我就行。 |
| 我 | 好的明白，我这就去准备。 |
```

- 这段是**每次重建聊天都会铺**的开场白，所以写「已经发生过的事」，不要写待办
- 「（发送文件：《…》）」这类动作直接写进「话」里，程序会当普通气泡显示
- 没写这一节的公司会退回程序自带的「互报名字」两句
